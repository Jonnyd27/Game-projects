# Paint It All Project
This is a project involving a pixelated sprite character named Peirre. He has unique abilities and different colors to chooose from in order to engage with different enemy types. It involves a simple system where you have to paint the enemy you encountered back to its original state. For example, there is a frog that has been
drained of its color. This has caused it to become hostle and damage Peirre. He has to use a combination of green and blue, while avoiding the frog by jumping and dashing in order to restore the enemy to its proper state. 
This project is ongoing. It utilizes the Godot engine as well as the built in language GDScript. 
My ultimate plan for the game will feature different environments with suiting enemies to restore their color, as well as some unique boss fights surrounding the ideas of paint and losing color. I.E A giant eraser or an ink pen.
